# AI model and runtime notices

## Qwen3-0.6B

AI Clipper can optionally download and run the Qwen3-0.6B language model locally on the device for transcript-level semantic highlight selection.

- Model repository: https://huggingface.co/litert-community/Qwen3-0.6B
- Model file used: Qwen3-0.6B.litertlm (approximately 586 MB)
- Model license: Apache License 2.0
- Base model: Qwen/Qwen3-0.6B
- No model API key, cloud inference endpoint, or per-request fee is required. The model is downloaded once by the app and then runs locally.

## LiteRT-LM

The Android runtime is provided by Google's LiteRT-LM Android library:
- Maven artifact: com.google.ai.edge.litertlm:litertlm-android:0.18.0
- Project: https://github.com/google-ai-edge/LiteRT-LM

Review the upstream model and runtime repositories for complete license texts, notices, model limitations, and acceptable-use requirements before redistribution.
